# 华悦官网苹果风首页原型设计规格

- 日期：2026-05-27
- 文件目标：新增一版独立 HTML 原型，不覆盖 2026-05-26 版本。
- 预览目标：本地 HTTP 访问，供浏览器视觉沟通使用。

## 设计判断

当前版本的问题不是局部配色，而是整体叙事仍像传统企业软件官网：模块密、卡片多、信息压得太近。苹果风重做的目标，是把华悦官网从“解释能力清单”改成“表达一种清晰、可信、有高级感的管理系统建设能力”。

本版采用“苹果产品叙事风”，不是复制苹果官网的品牌元素。页面以大留白、强主标题、低噪声产品视觉、分屏章节和克制客户陈列为核心。

## 页面结构

1. 顶部导航：`首页 / 解决方案 / 客户案例 / 本地服务 / 关于华悦`，半透明白底，轻毛玻璃效果。
2. 首屏：居中大标题，回答“华悦是谁、能做什么、服务过谁”。视觉中心是一组管理链路产品化图形。
3. 代表客户：横向克制展示客户名称，不使用“客户证据”等生硬叫法。
4. 问题洞察：说明客户不是没有系统，而是系统、流程、数据和责任没有真正连起来。
5. 解决方案：按三类能力组织为三段产品章节：
   - 核心 ERP 系统建设
   - 泛 ERP 系统建设
   - 各类定制软件开发
6. 客户案例：按后台排序值展示，海报感更克制，突出客户名称、管理复杂度和结果。
7. 本地服务：把 `20年+ / X名PMP / X个以上 / 本地团队` 组织成本地交付优势，不放首屏。
8. 关于与联系：只展示地址、电话、地图定位。

## 视觉规则

- 主色以黑、白、银灰为主，蓝色只做行动入口和关键连接线。
- 背景不用暗黑科技大屏，不用粒子、炫光、厚重仪表盘。
- 首屏标题优先级最高，视觉图形为标题服务，不抢阅读中心。
- 卡片数量减少，间距增大，重要内容用章节级大标题承载。
- 客户案例不做后台列表，不做密集网格。
- 移动端优先保证标题、段落和按钮不溢出。

## 文案边界

- 不出现“客户证据”“复杂组织数字化管理服务商”“服务能力”。
- 不在解决方案中直接写“适合国企平台、公立医院、集团总部”等目标客户标签。
- 案例区可以自然出现真实客户名称，由案例证明华悦能力。
- 保留首屏主问题方向：系统越来越多，为什么管理还是看不清、推不动、追不到？

## 验收标准

- HTML 独立打开可完整展示，不依赖构建。
- 通过 HTTP 预览，不使用 file 协议。
- 导航、首屏、解决方案、案例、本地服务、联系信息完整。
- 桌面端 1280 宽度无横向溢出。
- 移动端 390 宽度无横向溢出。
- 解决方案三类能力与客户案例素材来自项目官网素材文档。
